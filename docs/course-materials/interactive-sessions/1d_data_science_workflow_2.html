Pick up where Part 1 left off

We are in a fresh notebook, so first re-run the workflow from Part 1 to rebuild df and monthly_means.

✅ Canonical cell. Copy and run it exactly:

Code 
import pandas as pd
import matplotlib.pyplot as plt

url = "https://eds-217-essential-python.github.io/data/toolik_weather.csv"
df = pd.read_csv(url)

monthly = df.groupby('Month')
monthly_means = monthly['Daily_AirTemp_Mean_C'].mean()

Step 6: Visualize 📊

Visualize means turning numbers into a picture you can read quickly. The simplest plot is a line plot with plt.plot().

✅ Canonical cell. Copy and run it exactly:

Code 
plt.plot(monthly_means)
plt.title("Toolik Monthly Temperatures")
plt.xlabel("Month")
plt.ylabel("Temperature (°C)")
plt.show()

The same twelve numbers now show a clear seasonal cycle. We can also draw them as bars with plt.bar(). Copy the first line exactly. The month numbers for the x-axis come straight from your monthly_means.

Code 
plt.bar(monthly_means.index, monthly_means)
plt.title("Toolik Monthly Temperatures")
plt.xlabel("Month")
plt.ylabel("Temperature (°C)")
plt.show()
🔁 Change one thing

Change only a label. The data stays exactly the same. Pick one new title from this menu and re-run:

Step 7: Export 💾

Export means saving your results so you or a collaborator can use them later. This is the foundation of reproducible science. monthly_means.to_csv(...) writes your summary to a file.

✅ Canonical cell. Copy and run it exactly (in your notebook):

monthly_means.to_csv("monthly_means.csv", header=True)

Open the Explorer in Positron and you will find monthly_means.csv. It looks like this:

🔁 Change one thing

Change only the file name. Pick one and re-save:

  • monthly_means.to_csv("monthly_temps.csv", header=True)
  • monthly_means.to_csv("toolik_monthly.csv", header=True)
  • monthly_means.to_csv("my_results.csv", header=True)

Same data, new file. Your monthly_means in memory stays the same.

✍️ Say it in a sentence (optional)

Name what you saved. For example, set filename = "monthly_means.csv" and then print f"I saved my results to {filename}."

Naming what you just did: the 10-step workflow

You just did it. Here is the workflow you worked through, named in full. Every analysis in this course, and in your career, is some path through these ten steps:

Today you traveled Import → Explore → Group → Aggregate → Visualize → Export, skipping the steps we have not taught yet. That is normal. Few analyses use every step, and they always happen in this order.

Key Points

  • Visualize with plt.plot() and plt.bar(). Label with plt.title(), plt.xlabel(), and plt.ylabel(). Today you change labels only.
  • Export results with .to_csv("filename.csv") so your work is saved and reproducible.
  • The complete ten-step workflow is Import, Explore, Clean, Filter, Sort, Transform, Group, Aggregate, Join/Reshape, and Visualize.
  • You now know the plan for the whole course. Each of the next six days teaches a piece of this same workflow.
